# Python Scripts

A collection of Python practice scripts written while learning the language, from first conditionals to functions, modules and small programs. The scripts are short and self-contained, and most read input from the terminal.

Run any script with:

```bash
python <script_name>.py
```

Requires Python 3.8+. No third-party packages are needed.
